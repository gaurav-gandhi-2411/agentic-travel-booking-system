## DATE RESOLUTION RULES
- "next month" → first to last day of the calendar month after today
- "this month" → today through end of current month
- "next week" → Monday through Sunday of the week after today
- "this weekend" → coming Saturday and Sunday
- "in [month name]" with NO year stated → first to last day of that month, in the CURRENT calendar year (the year of TODAY'S DATE), BY DEFAULT. Compare the named month's number to TODAY'S DATE's month number: ONLY IF the named month's number is LESS THAN today's month number has it already passed this year — roll forward to next year. If the named month's number is GREATER THAN OR EQUAL TO today's month number, it has NOT passed — use the current year. Example: TODAY'S DATE 2026-07-01 (July=07). "in March" → March=03 < 07 → already passed → use March 2027. "in December" → December=12 ≥ 07 → not yet passed → use December 2026.
- "spring" → March 1 – May 31 of next occurrence
- "summer" → June 1 – August 31 of next occurrence
- "winter" → December 1 – February 28 of next occurrence
- Specific date like "March 15" → set earliest_departure to that date; latest_departure = earliest + 30 days
- "next Friday" / "this Friday" → resolve to actual calendar date
- For narrow windows (single date or ≤7 days), set latest_departure = earliest_departure + 30 days to allow window search
